# 🎮 Number Guessing Game

Интерактивная консольная игра «Угадай число». Программа загадывает случайное число от 1 до 100, а игрок пытается его угадать, получая подсказки «больше/меньше». Есть три уровня сложности, подсчёт попыток, таймер и возможность сыграть ещё раз.

Проект реализован на **Go** без использования внешних библиотек — только стандартная библиотека.

---

## ✨ Возможности

- 🎯 Случайное число от 1 до 100 при каждом запуске
- 💬 Интерактивный диалог с подсказками «больше/меньше»
- 🎚 Три уровня сложности:
  - **Easy** — 10 попыток
  - **Medium** — 5 попыток
  - **Hard** — 3 попытки
- 📊 Подсчёт количества попыток
- ⏱ Замер времени, затраченного на игру
- 🔄 Возможность сыграть ещё раз без перезапуска
- 🛡 Обработка некорректного ввода (буквы, пустой ввод, неверный диапазон)
- 🎮 Защита от stack overflow через циклы вместо рекурсии

## 🚀 Установка и запуск

1. Склонируйте репозиторий:
```bash
git clone <адрес-репозитория>
cd number-guessing-game
```

2. Запустите игру:
```bash
go run main.go
```

Или соберите бинарник и запустите:
```bash
go build -o guess-game main.go
./guess-game
```

> **Для Windows** используйте `guess-game.exe` вместо `./guess-game`.

---

## 📖 Как играть

1. **Выберите сложность** (1, 2 или 3).
2. **Вводите числа**, получая подсказки:
   - `Incorrect! The number is greater than X.` — загаданное число больше
   - `Incorrect! The number is less than X.` — загаданное число меньше
3. **Угадайте число** до того, как закончатся попытки.
4. После победы или проигрыша можно **сыграть ещё раз** (Y/N).

## 🛡 Обработка ошибок

Программа корректно обрабатывает следующие ситуации:

- **Некорректный ввод** (буквы, символы) — сообщение об ошибке и повторный запрос
- **Неверный уровень сложности** (число не от 1 до 3) — повторный запрос
- **Неверный выбор повтора** (не Y и не N) — повторный запрос
- **Исчерпание попыток** — сообщение `GAME OVER!` и предложение сыграть ещё раз

## 🛠 Технологии

- Язык: **Go 1.22+**
- Использованы только пакеты стандартной библиотеки:
  - `math/rand/v2` — генерация случайных чисел
  - `bufio` — чтение ввода пользователя
  - `strconv` — конвертация строк в числа
  - `strings` — работа со строками (ToUpper, TrimSpace)
  - `time` — замер времени игры
  - `os` — работа с stdin

## 🔧 Известные проблемы и доработки

Следующие моменты требуют полировки:

- [ ] **Создание `bufio.Scanner` в каждом цикле** — создаётся новая инстанция на каждой итерации, что неэффективно. Нужно создать один scanner в `main` и передавать как параметр во все функции.
- [ ] **Сообщение `You have 5 chances` в `main`** — жёстко прописано, но количество попыток зависит от сложности. Нужно убрать или сделать динамическим после выбора сложности.
- [ ] **Лишние пробелы в `fmt.Print`** — например, `Enter your guess:  ` с двумя пробелами в конце. Нужно убрать дублирование пробелов.
- [ ] **Отсутствие `\n` вCongratulations** — строка победы не заканчивается переносом. Нужно добавить `\n` в конце `fmt.Printf`.
- [ ] **Отсутствие обработки EOF (Ctrl+D / Ctrl+Z)** — при принудительном закрытии stdin программа может вести себя непредсказуемо. Нужно проверять `scanner.Scan()` и корректно обрабатывать конец ввода.
- [ ] **Опечатка в комментарии** — `Enter num of difficult` → `Enter the difficulty level`.

## 🚀 Запланированные фичи

### 1. История попыток
Показывать игроку список всех чисел, которые он вводил в текущей партии.

**Планируемый вывод при победе:**
```
Congratulations! You guessed 62 in 5 attempts.
Your guesses: 50, 75, 60, 65, 62
```

### 2. Система рекордов
Сохранять лучший результат (количество попыток) в файл `records.json` для каждого уровня сложности.

**Планируемый синтаксис:**
```bash
# Автоматически при каждой игре
New record on Easy: 4 attempts (previous: 6)!
```

### 3. Настраиваемый диапазон чисел
Позволить выбирать диапазон чисел в начале игры.

**Планируемый выбор:**
```
Select range:
1. 1-50 (easier)
2. 1-100 (standard)
3. 1-1000 (harder)
```

### 4. Расширенная статистика
Показывать в конце сессии сводку по всем сыгранным партиям:
- Всего партий
- Побед/поражений
- Среднее количество попыток
- Лучшее время

### 5. Мультиплеер (два игрока)
Режим, где два игрока по очереди угадывают числа, а побеждает тот, кто угадал за меньшее количество попыток.

### 6. Подсказки
Возможность получить дополнительную подсказку (ценой потери попытки):
- Число чётное/нечётное
- Число простое/составное
- Сумма цифр числа
